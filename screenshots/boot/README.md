# Boot artwork previews

These files were rendered by `distro/boot/generate.py` from the supplied video. They are animation previews, not screenshots of a booted ISO. The MP4 shows the intro once and three background cycles. The clean PNG supplies Calamares's welcome artwork.

Generated at the original 1280×720 resolution and 24 fps. The full Plymouth PNG payload totals 317,204,302 bytes before initramfs compression. Boot rendering speed and the visual loop boundary still require target-machine testing.
