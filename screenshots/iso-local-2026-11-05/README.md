# صور من الإقلاع الفعلي للـISO المحلي

الصورتان من تشغيل `11984ec` داخل QEMU TCG، بدقة 1280×720.
ليستا صورًا مولّدة ولا معاينة فيديو. الصورة الثابتة لا تثبت سلاسة الأنيميشن.
هذه صور شاشة الإقلاع فقط؛ صور الواجهة من النسخة الحالية لم تُعتمد بعد.
